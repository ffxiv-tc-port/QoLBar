# QoLBar

自訂捷徑列插件：以圖形化介面建立可自訂的按鈕列，功能類似快捷欄與巨集，可執行指令、開啟分類選單、觸發巨集等。

原作者：[UnknownX7/QoLBar](https://github.com/UnknownX7/QoLBar)

## 核心概念

- **列（Bar）**：自訂選單，功能類似快捷欄
- **捷徑（Shortcut）**：列上的按鈕，功能類似巨集
- **分類（Category）**：點擊後彈出更多捷徑的捷徑
- **間隔（Spacer）**：無實際功能，僅用於排版或標示
- **輪盤（Pie）**：以熱鍵呼叫的環形選單

## 操作

- 左鍵：執行捷徑／移動未鎖定的列
- 右鍵：開啟捷徑或列（周圍背景）的設定
- Shift + 右鍵：在該列或分類新增捷徑
- 雙擊或 Ctrl + 左鍵：於滑桿等欄位輸入自訂數值

## 功能

- 指令：`/qolbar`（開啟設定視窗）、`/qolicons`（開啟圖示瀏覽器）、`/qolvisible [on|off|toggle] <列>`（依名稱或編號顯示/隱藏列）
- 工具提示：捷徑名稱加 `##` 後接文字即為提示內容
- 遊戲圖示：捷徑名稱用 `::編號` 顯示遊戲內圖示，支援修飾參數（如加上快捷列外框 `::f編號`）
- 內建圖示瀏覽器（`/qolicons`），可搜尋並複製圖示 ID，也支援匯入自訂圖示
- 捷徑模式：一般／遞增（依序執行每一行）／隨機
- 列的靠邊與對齊；可拖出遊戲視窗外（需搭配 Dalamud 的 Undocked 選項）
- 輪盤（Pie）：以熱鍵呼叫的環形選單，即使該列被 `/qolvisible` 隱藏，熱鍵仍可用
- 條件集（Condition Set）：依目前遊戲狀態自動顯示/隱藏列
- 執行巨集：`//m編號` 執行個人巨集，`//m100` 起執行共用分頁巨集
- 自訂巨集：`//m` 不接編號時，可直接在捷徑內寫入多行巨集指令
- 指令支援 `//` 開頭的註解
- 匯出／匯入：可將列或捷徑轉為文字區塊分享、匯入
